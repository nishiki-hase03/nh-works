slimEditor

v1.0 - 極薄・自動保存テキストエディタ

概要

slimEditorは、思考を妨げない究極のシンプルさを追求したテキストエディタです。
保存操作すら不要。思いついたことを書き留め、Escキーを押すだけで自動的に「本文冒頭＋日時」のファイル名で保存して終了します。

●即時自動保存

Escキー一発で終了と同時に保存。ファイル名は本文の先頭5文字から自動生成されます。

●高度なカスタマイズ

透過率、フォントサイズ、ダークモード切り替えなど、執筆環境を瞬時に最適化できます。

●最前面固定機能

F1キーで常に最前面に表示。ブラウザや資料を見ながらのメモ書きに最適です。

●ポータブル設計

インストール不要の単一実行ファイル。USBメモリ等に入れて持ち運びも可能です。

操作ガイド / ショートカット

操作内容 キーボード / マウス
保存して終了 Esc
保存せずに終了 Shift + Esc
最前面表示の切替 F1
ライト/ダークモード切替 F6
フォントサイズ調整 Ctrl + ↑ / ↓ または Ctrl + Wheel
透明度調整 Alt + ↑ / ↓ または Alt + Wheel

おすすめ設定：タスクバー固定

slimEditorをタスクバーにピン留めすることで、キーボードだけで「一瞬で起動→メモ書き→Escで保存終了」という流れるような操作が可能になります。

Windows 爆速起動ショートカット

Win + 数字キー

※左から1番目に置いた場合、Win+1で起動します。

安全性とビルドについて

本ソフトは GCC (MinGW-w64) コンパイラを用いてビルドされ、正規のWin32 APIのみを使用しています。 単一の実行ファイルによるシンプルさを重視しており、不透明なライブラリや常駐処理は一切含まれていません。

※極小サイズのバイナリファイルという特性上、一部のセキュリティソフトでごく稀に誤検知される場合がありますが、 システムへの悪影響を与えるコードは含まれておりませんのでご安心ください。
