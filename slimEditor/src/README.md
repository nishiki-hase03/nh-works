# Slim Editor

「とにかく軽量・シンプル」をコンセプトにした、Win32 API製の実用的なメモ帳アプリです。
インストール不要、単一の実行ファイルのみで動作します。

## 特徴
- **超軽量**: 実行ファイルサイズが小さく、メモリ消費も最小限です。
- **自動保存**: 終了時にタイムスタンプ付きのファイルとして実行ファイルと同じディレクトリに自動保存します。
- **最前面表示**: 他のウィンドウに隠れずにメモを取ることができます。
- **透過機能**: 背景の資料を透かしながら入力が可能です。

## 操作方法
| キー / 操作 | 機能 |
| :--- | :--- |
| **ESC** | 自動保存して終了 |
| **Shift + ESC** | 保存せずに終了 |
| **F1** | 最前面表示の切り替え (タイトルに [Topmost] と表示) |
| **Ctrl + Up / Down** | フォントサイズの拡大 / 縮小 |
| **Alt + Up / Down** | ウィンドウの透過率を上げる（不透明にする） / 下げる（透明にする） |
| **F6** | ライトモード / ダークモードの切り替え |
| **Ctrl + マウスホイール** | フォントサイズの拡大・縮小 |
| **Alt + マウスホイール** | ウィンドウの透過率（透明度）の調整 |

## インストール
配布パッケージ内の `slimEditor.exe` を任意のフォルダにコピーして実行してください。設定ファイルやレジストリは使用しません。
