# 📄 標準Markdown機能テスト用サンプル

このドキュメントは、Markdownエディタの標準的な表示および編集機能を確認するためのサンプルです。

---

## 1. テキスト装飾
日常的に使用される基本的な装飾のスタイルを確認します。

- **太字 (Bold)**
- *斜体 (Italic)*
- ~~打ち消し線 (Strikethrough)~~
- `インラインコード (Inline Code)`
- [外部リンクへのリンク (Link)](https://www.google.com)

## 2. リスト構造
ネストされたリストやタスクリストの挙動を確認します。

### 箇条書き
- 親項目 1
  - 子項目 1-1
    - a
  - 子項目 1-2
- 親項目 2

### 番号付きリスト
1. 手順 1
2. 手順 2
3. 手順 3

### タスクリスト
- [x] 完了済みのタスク
- [ ] 未完了のタスク

## 3. 引用と情報・警告
> これは標準的な引用（Blockquote）です。
> 複数行にわたる説明や、他者からの助言を記述する際に使用します。

---

## 4. テーブル (表)
設計書や仕様書で頻繁に使用されるテーブルの編集・同期を確認します。

| 項目名 | 型 | 必須 | 説明 |
| :--- | :---: | :---: | :--- |
| `user_id` | UUID | ✅ | ユーザーの一意な識別子 |
| `username` | String | ✅ | ログインに使用する名称 |
| `bio` | Text | ❌ | ユーザーの自己紹介文（任意入力） |
| `created_at` | DateTime | ✅ | アカウント作成日時 |

## 5. コードブロック
シンタックスハイライト（もしあれば）や、コピーのしやすさを確認します。

```javascript
// サンプルコード
function greet(name) {
```
